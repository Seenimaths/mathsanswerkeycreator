# Maths Answer Key Studio — Bulk Multi-Photo, AI Vision (Gemini/DeepSeek) & KaTeX PDF

A free, MIT open-source, GitHub Pages-ready web app for teachers and educators to upload **multiple question paper photos (2–10 pages)** or **PDFs**, extract math equations accurately in KaTeX Math Mode (`$2x^2$`, fractions, roots, matrices), auto-solve using **Google Gemini 2.5 Flash Vision**, **DeepSeek R1**, **OpenRouter Free Open-Source Models (Gemma 3 Vision / Qwen 2.5 VL / DeepSeek R1)**, or the **Built-in Offline Math Engine**, and export a neatly aligned **100-Mark / 50-Mark DGE Part-Wise Answer Key PDF**.

## Key Features
- **Bulk Multi-Photo & PDF Page Queue**: Upload 2–10 photos at once or a multi-page PDF, preview thumbnails in page order, and extract & solve all pages in one click.
- **Proper Math-Mode Extraction (`$2x^2$` Fix)**: Vision AI reads equations straight into LaTeX, plus a built-in **Fix Math Mode** normalizer repairs OCR artifacts (`2x2 -> $2x^2$`, fractions, roots, degrees) with a live KaTeX preview.
- **Open-Source & Free AI Models (BYOK)**: Switch seamlessly between Offline Math Engine, Gemini 2.5 Flash Vision, OpenRouter Free (DeepSeek R1, Gemma 3 27B Vision, Qwen 2.5 VL), and DeepSeek API.
- **100-Mark & 50-Mark Part-Wise Tables**: Generates PART-I, PART-II, PART-III, and PART-IV marking schemes with step marks and zero General Instructions clutter.

## Host Free on GitHub Pages
1. Extract this ZIP and upload all files to a public GitHub repository.
2. Open **Settings -> Pages**, choose `main` branch and `/ (root)`, and click **Save**.

# Maths Answer Key Studio (PWA • MathJax • Tamil & English • A4 Print-Safe)

An open-source, installable **Progressive Web App (PWA)** for GitHub Pages that generates official **100-Mark & 50-Mark Part-Wise Mathematics Answer Keys** in **English (`Cambria Math` / `Times New Roman`)** or **Tamil (`Google Noto Serif Tamil`)** with **MathJax v3 SVG** equations and default **A4 15mm margins** (zero margin cut-out on Print and Download PDF).

## Highlights
- **Installable PWA (Address Bar Install)**: Includes `manifest.json`, `sw.js`, and 192px/512px PNG icons so Chrome, Edge, and Android show the **Install App** icon right in the browser address bar when hosted on GitHub Pages.
- **Default A4 Margins (Zero Cut-Out)**: Locked A4 portrait `15mm` margins (`@page { size: A4 portrait; margin: 15mm 14mm; }`) and responsive MathJax SVG fitting.
- **Tamil & English Generate Toggle**: Instant switch between English (`Cambria Math` / `Times New Roman`) and Tamil (`Noto Serif Tamil`) for headers, Part titles (`பகுதி – I..IV`), option codes (`(அ)-(ஈ)`), answers, and AI prompts.
- **Bulk Multi-Photo & PDF Upload + AI Vision**: Supports Gemini 2.5 Flash Vision, DeepSeek R1, OpenRouter Free (Gemma 3 Vision / Qwen 2.5 VL), and Offline Smart Math Engine.

## Deploy Free on GitHub Pages
1. Extract this ZIP and upload all files (`index.html`, `manifest.json`, `sw.js`, `icons/`, `.nojekyll`, `LICENSE`, `README.md`) to a public GitHub repository.
2. Open **Settings -> Pages**, select `main` branch and `/ (root)`, and click **Save**.
3. Open your GitHub Pages HTTPS URL — click the **Install** icon in your browser address bar to install it as a desktop/mobile app!

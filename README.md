# Maths Answer Key Studio — MathJax v3 SVG, Print-Fixed PDF & AI Vision

A free, MIT open-source, GitHub Pages-ready web application for generating official **100-Mark & 50-Mark DGE Part-Wise Mathematics Answer Keys** with **MathJax v3 SVG** rendering, bulk multi-photo/PDF upload, AI Vision extraction (Gemini 2.5 Flash, DeepSeek R1, OpenRouter Gemma 3 Vision & Qwen 2.5 VL), and bulletproof A4 Print / PDF export.

## Key Fixes & Features
- **Zero Blank Page Print & PDF**: Fixed responsive print CSS so `#preview-column` and `#answer-key-sheet` always render full-width on A4 portrait print and direct PDF download.
- **MathJax v3 SVG (`fontCache: 'none'`)**: Every equation (`$2x^2$`, fractions, matrices, square roots) renders as self-contained inline SVG for crisp print, PDF, and standalone HTML export.
- **Bulk Multi-Photo & PDF Upload Queue**: Upload 2–10 question paper photos or a multi-page PDF and process all pages in order.
- **100-Mark & 50-Mark Part-Wise Tables**: Supports PART-I, PART-II, PART-III, and PART-IV with step marks and zero General Instructions clutter.

## Deploy Free on GitHub Pages
1. Extract this ZIP and upload all files to a public GitHub repository.
2. Open **Settings -> Pages**, choose `main` branch and `/ (root)`, and click **Save**.
